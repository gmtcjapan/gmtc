Project 1: GMTC Website Development

03/14/2025

Skills：HTML and CSS

GMTC Japanは、2024年9月末に立ち上げられた学生主導のSTEM団体です。その最初のプロジェクトとして、私たちは自分たちの公式ウェブサイトを作ることに 挑戦しました。もともと創設メンバーのうち2人はHTMLの基本的な知識を持っていたため、それを活かしながら、他のメンバーも一緒にWeb制作を学び、チーム全 体で制作を進めました。

最初のステップとしてFigmaを使い、ページ全体のデザインや構成を話し合いました。「見やすく・伝わりやすく・私たちらしい」デザインを目指し、色やフォント 、写真の使い方までこだわりました。デザインが完成した後は、HTMLとCSSでの実装に移り、それぞれの得意分野に合わせてタスクを分担。誰もが初めての本格的 なWeb開発だったため、エラーや配置崩れ、レスポンシブ対応など、予想以上に苦労しました。

制作には約4ヶ月ほどかかりましたが、チームで試行錯誤しながら協力し、ついにGitHub Pagesでの公開に成功。その後、独自ドメインとも接続し、現在では世界 中からアクセスできる状態になっています。プロジェクトを通して、技術だけでなく、コミュニケーション力やプロジェクトマネジメントの大切さも学ぶことができ ました。

この経験は、私たちGMTCの原点であり、「自分たちでつくる」という意志の象徴でもあります。今後はサイトにイベント申し込み機能や参加者向けのポータルも追加 予定です。ぜひ、成長していく私たちのウェブサイトも見守ってください。

As the very first project of GMTC Japan, we decided to create our official website from scratch. Since two of our founding members already had basic knowledge of HTML, we thought it would be the perfect opportunity for the entire team to learn web development together and build something meaningful that represents us.

We started by designing the layout on Figma, carefully choosing the color scheme, fonts, and structure to match our identity. Our goal was to create something simple, readable, and uniquely “ours.” Once the design was finalized, we moved on to implementation using HTML and CSS, dividing tasks based on each person’s skills and learning goals. Since most of us were new to building websites, we ran into lots of challenges—from layout bugs to responsive design issues—but we kept pushing forward.

After about four months of work, we successfully launched the website using GitHub Pages, and later connected it to a custom domain. This was more than just a coding project—it taught us the importance of teamwork, communication, and perseverance.

This website is the starting point of GMTC Japan. It reflects our passion and commitment to STEM education. We’re already working on adding features like event sign-ups and a member dashboard, so stay tuned as our digital space continues to grow!
