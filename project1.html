Project 1: GMTC Website Development

03/14/2025

Skills：HTML And CSS

2024年9月末に立ち上げられたGMTC Japanです。初めのプロジェクトとして、創設者のうち二人はHTMLの 経験があったため、全員でWebサイト制作に挑戦することにしました。まずはFigmaでデザインをし、その後HTML,CSSを使用して全員で役割分担をしながら作りました。 始めてから４ヶ月ほどかかってしまいましたが、最終的にはGithub Pagesに公開し、その後ドメインと繋げて、公開することができました！ メンバー感想：

As our first project for GMTC Japan, we decided to create our gmtc japan website, since 2 of our members were already familiar with HTML. We used Figma to first design our website, and then programmed on github, using HTML and CSS. It took us around 4 months to create this, but we were finally able to post our website on Github pages and then connect it to a domain.
